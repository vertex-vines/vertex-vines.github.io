NSF VINES · Track 1

Quantum-Ready and AI-Enabled by Design: Resilient and Deployable Next-Gen Cellular Networks

A vertically integrated framework for resilient, post-quantum secure NextG networks that brings together new cryptography, secure cellular protocols, and privacy-preserving AI, all evaluated on large-scale NSF wireless testbeds.

Purdue University The University of Texas at Dallas University of South Florida
A4: Resilience B4: Security & Privacy Post-Quantum Cryptography 5G / NextG Protocols Federated Learning POWDER · Colosseum

01Summary

NextG networks have to keep performing through failures, attacks, and disruptions while protecting sensitive data and user privacy. Deployments are growing fast, and attackers have more remote and physical access to networking equipment than before, so protocols need to support distributed trust and stay secure even when parts of the network are breached. Quantum computers also threaten today's cryptographic foundations, so protocols need to be post-quantum (PQ) secure to stay safe in the long term.

This project develops B4: Security & Privacy foundations together with A4: Resilience to deliver practical, scalable advances for NextG networks.

Goal. Create, develop, and evaluate a vertically integrated framework for resilient and PQ-secure NextG networks. It introduces new resilient, PQ-secure, and efficient cellular protocols and new PQ-safe signature and authentication schemes, and combines them with distributed, privacy-preserving AI techniques.

Research questions

  1. How can we strengthen NextG security and resilience against threats such as fake base stations, and make critical cellular protocols (5G-AKA, AKMA) PQ-secure?
  2. How can we design PQ-secure cryptographic schemes (e.g., signatures, commitments) that are compact, identity-friendly, and support distributed deployment in constrained network environments?
  3. How can AI-driven systems such as federated learning be made provably resilient to model manipulation, adversarial updates, and PQ attacks without sacrificing utility or privacy?
  4. What system-level tradeoffs (computation vs. communication, key management, backward compatibility) come up when PQ-secure, resilient protocols are deployed in real NextG systems?
  5. How can we build an evaluation fabric for reproducible, scalable validation of NextG protocols under real-world constraints, with broad community access?

02Research Thrusts

Three thrusts build on one another: PQ primitives from Thrust 1 are used by the protocols in Thrust 2, and Thrust 3's trustworthy ML uses both. All three are validated end to end on the RIPPLE evaluation fabric.

Thrust 1

Resilient, Compact and Private PQC for NextG

Lead: Attila A. Yavuz (USF)

  • Task 1.1: Efficient identity-based signaturesLattice IBS with uniformly random keys and signatures, enabling certificate-free authentication without certificate chains.
  • Task 1.2: Key-compromise-resilient threshold signaturesDirect secret sharing of uniform signing keys, so base stations and core network (CN) nodes can sign jointly.
  • Task 1.3: Privacy-enhanced PQ blind protocolsAdditive blinding with no auxiliary rejection steps, for unlinkable, low-latency authentication.
  • Task 1.4: Security analysis and optimizationProofs in the QROM (EU-CMA-UC, t-EU-CMA, blindness) and optimized ARM implementations.
Thrust 2

Secure and Resilient NextG Cellular Protocols

Lead: Imtiaz Karim (UT Dallas)

  • Task 2.1: PQ-secure UE bootstrapping authenticationMAYO root of trust provisioned to the eSIM, plus temporal Falcon keys and TESLA for SIB authentication.
  • Task 2.2: Resilient AKA protocolsNextG-AKA/AKMA built on key-homomorphic PRFs and secret sharing, so long-term secrets survive the compromise of some CN components.
  • Task 2.3: Secure MVNO–MNO protocolsAnonymous BS–CN authentication, privacy-preserving revocation, and distributed audit logging.
  • Task 2.4: Formal security analysisEnd-to-end symbolic verification with Tamarin, ProVerif, and DeepSec.
Thrust 3

PQ-Secure and Resilient AI for NextG

Lead: Rouzbeh Behnia (USF)

  • Task 3.1: AI-based intrusion detectionO-RAN federated learning that combines UE-centric and network-centric views across protocol layers for low false positives.
  • Task 3.2: PQ-secure FL with differential privacyMulti-agent, RL-driven coordination that tunes per-client privacy budgets.
  • Task 3.3: Proof of integrity for FLLattice-based commitments that let clients verify their updates were included in aggregation, with no trusted aggregator.
  • Task 3.4: Security analysisEvaluation against membership-inference and reconstruction attacks, plus reduction proofs to SIS/LWE.
Evaluation

RIPPLE Evaluation Fabric

Resilient Intelligent Protocol Platform for Large-scale Evaluation

  • Portable PQ modulesModular crypto libraries that plug into open-source stacks (srsRAN, OpenAirInterface, Open5GS).
  • Large-scale testbedsColosseum for emulation at scale and NSF POWDER for city-scale over-the-air trials with mobility and handover.
  • Open accessPublic containers, profiles, standardized benchmarks, and a future leaderboard for PQ-secure NextG schemes.

07Software & Artifacts

All protocol specifications, formal models, ML models, datasets, and software from the project will be released under open licenses on GitHub and archived on Zenodo. Planned releases include:

  • PQ signature libraries (identity-based, threshold, blind) in portable C with ARM optimizations
  • PQ-secure bootstrapping, NextG-AKA/AKMA, and MVNO protocol implementations for srsRAN, OpenAirInterface, and Open5GS
  • Tamarin / ProVerif models of the designed protocols
  • O-RAN xApps for federated intrusion detection
  • RIPPLE containers and profiles for Colosseum and NSF POWDER

08Education & Outreach

Curriculum

Project results will feed new course modules on:

  • PQ-resistant protocols for cellular networks
  • ML techniques for cellular network security
  • Edge-computing-enabled cybersecurity

Modules will be integrated into courses such as CIS 4212/6214 Trustworthy and Privacy-preserving Cyberinfrastructures (USF) and a UT Dallas course on security and privacy of emerging technologies (6G, NTN). Students will also get hands-on testbed training on POWDER and Colosseum.

Broadening participation

  • Purdue: undergraduate research through the CS Office of Student Experience.
  • UT Dallas: 5G/NextG security sessions at WEhack and the department's K–12 summer coding camps.
  • USF: privacy-preserving FL and PQC modules at Cybersecurity Day and Big Data Day for high-school students, and the CodeBreakhers summer camp.
  • Standards: engagement with 3GPP, GSMA, and ETSI.
